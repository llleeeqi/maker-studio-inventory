## 新状态模型

扫码页只维护一个 `ScanWorkflowState`：

```text
mode
item
weightG
quantity
location
sortingLocation
review
```

`review` 表示当前正在等待用户确认的单次输入：

```text
Item
Weight
Location
ModeSwitch
```

二维码识别后不会直接写入扫码会话。流程是：

```text
识别二维码
暂停相机分析
打开确认层
用户确认 -> 写入扫码会话 -> 恢复相机
用户取消 -> 会话不变 -> 恢复相机
```

## 已实现规则

```text
更新库存和绑定库位只能选择已经入库的物品
入库模式不能重复入库当前已在库物品
已归档物品不能重新入库、盘点、绑定或整理库位
替换物品时清空旧物品对应的重量、数量和库位
替换重量或库位时必须明确确认
耗材毛重必须大于空盘重量
零件必须有单重才能由重量计算数量
未知库位必须确认名称
未完成流程切换模式时必须确认清空
库位整理模式仍允许连续扫码自动更新库位
```

## 库存详情

库存项点击后展示：

```text
固定字段
当前状态
当前库位
毛重 / 空盘 / 可用重量
总重 / 单重 / 数量
入库、出库和更新时间
最近三条主流水
```

出库和归档从详情层触发，并再次确认后写入。
