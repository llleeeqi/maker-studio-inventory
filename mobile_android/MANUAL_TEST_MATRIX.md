# 0.4.1 验收表

2026-07-14 已在 Android 12 MuMu 模拟器完成库存闭环验收。测试页面使用仓库根目录的 `tools/index.html`；正常产品流程不提供手动 payload 输入。调试构建的受保护广播只用于自动化验收，release 构建为空实现。

## 验收前准备

```text
APK: studio-inventory-native-0.4.1-debug.apk
SHA256: 92db41731ff4464847b710fd63ca5c530546117b18c3e300e2d9a129fa812db5
版本: 0.4.1 (41)
Android: 12 及以上
```

首次测试建议清空 App 数据，打开 `tools/index.html`，使用默认 `TEST` 批次。每个二维码只通过相机扫描。

## 1. 相机和确认层

1. 点击“开始扫描”，确认相机区域不会突然撑高或覆盖顶部模式按钮、底部导航。
2. 扫任意有效二维码，确认相机立即暂停，并只出现一个确认层。
3. 保持二维码对准相机 3 秒，确认不会重复弹窗或重复写入。
4. 点击取消，确认当前流程不变、确认层关闭、相机恢复。
5. 再次扫码并确认，确认数据进入底部当前流程，相机恢复。
6. 20 秒不扫码，确认相机自动暂停；点击开始扫描后可立即继续。
7. 打开软键盘编辑物品或库位名称，确认表单可滚动，按钮不被键盘遮挡。

## 2. 耗材入库

按顺序扫描：

```text
FIL-TEST-001 耗材标签
712.4g 重量码
LOC-TEST-001 测试库位
```

预期：

```text
耗材确认层显示品牌 Bambu、材料 PLA、颜色 white、空盘 200g
重量确认后显示毛重 712.4g，可用重量 512.4g
库位确认层允许确认“测试库位”名称
三步完成前不能入库
点击入库后物品状态为在库，库位为测试库位
流水新增一条入库，扫码日志保留三次扫码结果
底部当前流程消失
```

失败条件：毛重等于或小于 200g 时必须阻止确认。

## 3. 零件入库

按顺序扫描：

```text
PART-TEST-001 零件标签
420g 重量码
LOC-TEST-001 测试库位
```

预期：单重为 0.42g，自动数量为 1000；点击入库后流水记录数量和总重。

失败条件：清空单重后确认物品，再扫重量码，App 必须提示参数不足，不能计算数量。

## 4. 其他物品入库

按顺序扫描热风枪标签和测试库位，不扫描重量。

预期：其他物品不要求重量或数量；物品和库位确认后可入库。提前扫描的重量不能残留到其他物品流程。

## 5. 更新库存

1. 切换到“更新库存”。
2. 扫已入库的耗材或零件，再扫新的重量码。
3. 点击更新，确认库存数值改变，流水新增“更新重量/数量”。

失败条件：

```text
未入库物品不能盘点
更新库存模式扫描库位码应被忽略
没有物品时不能完成更新
```

## 6. 绑定和整理库位

绑定库位：切换到“绑定库位”，扫描已入库物品和库位，确认后完成绑定。该动作不进入主流水。

整理库位：单独扫描库位码，点击“整理该库位”，然后连续扫描多个已入库物品。物品应自动移动到该库位，不逐个弹确认；点击完成整理后退出整理状态。

失败条件：

```text
绑定库位模式扫描重量码应被忽略
未入库物品不能绑定或整理到库位
同一物品重复扫不能产生重复库存记录
物品已经在目标库位时应提示跳过，不更新库位时间、不重复写入成功日志
整理结束后再扫物品必须恢复普通确认流程
```

## 7. 会话替换和模式切换

1. 已确认一个物品后再扫另一个物品，必须提示替换；确认替换后清空旧重量、数量和库位。
2. 已确认重量或库位后再扫同类二维码，必须提示替换。
3. 流程未完成时切换模式，必须确认是否清空；取消后保留原模式和原流程。
4. 点击底部当前流程的取消，确认整个会话清空。
5. 切换到其他底部页面再返回扫码页，确认相机已释放并处于暂停状态，点击开始扫描后可重新启动。

## 8. 库存详情

点击库存列表中的耗材、零件和其他物品，确认详情层可滚动，并分别显示正确的固定字段、重量或数量、库位、时间和最近三条流水。

出库必须二次确认；完成后清空当前库位，但保留最后重量或数量。已出库物品允许重新入库。

归档也必须二次确认。归档后再扫描该标签，入库、盘点、绑定和整理库位都必须拒绝操作。

## 9. 打印和标签

新增页生成三类物品和库位标签，确认 40x30mm 预览不溢出。搜索打印机可手动关闭，开启自动连接后重启 App 应尝试连接上次设备。

打印 SDK 的二维码与排版仍需拿到真实打印机后确认：二维码可扫、右侧 18mm 区域不裁切、左侧三行文字可读。

## 通过标准

第 1-8 节已在 MuMu 完成。实体手机仍需复核真实相机画面、大字体和软键盘；第 9 节打印实测单独记录，不阻塞扫码库存流程验收。

附加验收：SQLite 直查确认更新库存只替换目标物品行，其他物品 `rowid` 不变，流水和扫码日志各自追加；库存搜索已验证品牌关键字和类型过滤；流水页仓库链接可拉起系统浏览器。
