# WebDAV 同步与备份 v1

更新时间：2026-07-14

实现状态：0.5.0 已完成。Android 12 MuMu 已通过真实 WebDAV 同步、本机/云端备份、系统文件导出/导入、恢复暂停和取消恢复验收；真实双实体设备并发冲突仍待后续复核。

## 目标

0.5.0 增加单用户、多设备、本地优先的 WebDAV 同步。同步不能阻塞扫码、入库、盘点、绑定库位、整理库位、出库或打印。

同步模型参考思源笔记 DejaVu 的核心原则，但库存对象粒度是完整物品记录，不实现笔记文件分块。

```text
本地 SQLite 立即提交
生成本地加密快照
前台定时检查 WebDAV refs/latest
取得云端锁
三方合并 base / local / remote
上传缺失对象和新索引
更新 refs/latest
释放云端锁
```

## 同步范围

参与日常同步：

```text
items
locations
transactions
同步设备、索引和冲突元数据
```

不同步：

```text
scan_logs
打印机地址和自动连接设置
WebDAV 本机凭据
相机和界面状态
```

`scan_logs` 可以进入手动全量备份，但不进入日常同步仓库。

## 云端仓库

```text
studio-inventory/
└── sync/v1/
    ├── objects/
    │   └── <sha256-prefix>/<sha256-rest>
    ├── indexes/
    │   └── <index-id>
    ├── refs/
    │   └── latest
    ├── devices/
    │   └── <device-id>.json
    ├── conflicts/
    └── lock-sync.json
└── backups/
```

对象和索引使用共享同步仓库密钥进行 AES-256-GCM 加密。对象路径由明文类型、实体 ID 和 JSON 内容的 SHA-256 决定；未变化内容复用原对象。

明文保留：

```text
refs/latest
设备登记的 ID、名称和最后在线时间
云端锁
```

## 快照索引

索引包含：

```text
schema
id
createdAt
deviceId
parentId
items: item_id -> object_hash
locations: location_id -> object_hash
transactions: tx_id -> object_hash
```

每个成功同步批次生成一个索引。默认保留最近 20 个同步索引；累计 100 个索引或 7 天未清理时，清理未被 latest、最近索引、冲突或备份引用的对象。

## 三方合并

三方状态：

```text
base: 当前设备最近一次成功同步的共同快照
local: 当前本地 SQLite 快照
remote: WebDAV refs/latest 指向的快照
```

规则：

```text
local == remote       -> 直接采用
local == base         -> 采用 remote
remote == base        -> 采用 local
local != base 且 remote != base 且 local != remote -> 冲突
```

物品是不可拆分整体，不按重量、库位或备注字段自动拼接。

主流水是不可变记录，按全局唯一 `tx_id` 合并。每条流水记录来源设备 ID 和名称。

## 冲突

同一物品并发修改时：

```text
保留本地版本作为当前展示
保存 base / local / remote 三个版本
物品标记为同步异常
禁止普通出库、盘点、绑定和整理库位
全局同步状态显示红色
```

处理方式：

```text
重新确认在库：扫码物品，按类型补重量/数量，扫描库位
确认已出库：二次确认，清空库位
确认归档：二次确认
```

解决后生成新权威快照和校正流水，旧冲突版本保留在同步历史中。

## 删除

只有 App 生成的新索引中缺少原实体，才构成版本化删除。WebDAV 上对象、索引或 `refs/latest` 被人工删除，不能解释成本地库存删除。

0.5.0 界面仍以出库和归档为主。同步协议支持版本化 remove，为后续安全彻底删除预留能力。

## 云端锁

```text
锁文件：lock-sync.json
刷新间隔：30 秒
过期时间：65 秒
发现其他设备持锁：每 5 秒重试，最多 3 次
```

超过重试次数时保留本地待同步状态，稍后重试，不显示红色。锁损坏、权限错误或长期无法释放时显示红色。

## 调度

前台同步间隔选项：

```text
3 秒
5 秒（默认）
10 秒
30 秒
60 秒
仅手动
```

该间隔同时用于本地变动防抖和前台检查 `refs/latest`。`latest` 未变化时不加锁、不下载对象。

立即触发同步：

```text
App 启动
回到前台
从其他页面返回扫码首页
退出前存在待同步变动
用户点击立即同步
```

后台任务交给 Android WorkManager，不使用常驻前台服务。

## 返回行为

```text
弹窗/详情打开：返回先关闭弹层
库存/新增/流水/同步中心：返回扫码首页，并在需要时触发同步
扫码首页无待同步数据：返回直接退出
扫码首页有待同步数据：第一次返回触发同步并提示再次返回
2 秒内再次返回：退出，后台继续处理
```

实体返回键和安卓侧滑返回使用同一逻辑。

## 状态标

全局标题栏右上角显示：

```text
灰色：未配置或离线
绿色：在线且同步完成
绿色加载圈：正在同步
红色：认证、权限、仓库损坏或冲突等需要人工处理的问题
```

点击进入独立“同步与备份”页面。

## 设备

启用同步时设备名必填，默认使用手机型号。内部使用随机设备 ID。

设备名冲突时：

```text
改名
接管设备名
取消
```

接管只停用旧设备登记，不删除它产生的库存、流水、快照和备份。

## 首次连接

```text
云端空、本地有数据：本地初始化云端
本地空、云端有数据：下载云端作为本地基准
两边相同：直接绑定
两边都有数据且无共同基准：安全合并 / 采用云端 / 本地重建云端
```

三种操作前都生成保护备份。

## 凭据和仓库密钥

WebDAV 密码使用 Android Keystore 加密保存在本机。同步仓库使用独立 32 字节随机密钥。

全量备份主体保持明文；WebDAV 密码和同步仓库密钥位于单独的 AES-GCM 加密凭据块中，使用用户设置的备份密码解密。

普通同步对象、诊断导出和扫码日志不能包含明文凭据。

## 备份

```text
本地自动备份：每天有变化时最多 1 份，保留 10 份
云端自动备份：每天有变化时最多 1 份，保留 30 份
手动备份：不自动删除
恢复、导入、清空云端、重建基准前：强制生成操作前备份
```

恢复后暂停自动同步。用户检查数据后选择取消恢复，或将恢复结果设为新的同步基准。

## 网络

只判断 Android 系统是否提供可用网络，不区分 Wi-Fi、移动数据或漫游。

默认要求有效 HTTPS。HTTP 必须显式开启不安全连接；不允许无条件忽略 HTTPS 证书错误。
