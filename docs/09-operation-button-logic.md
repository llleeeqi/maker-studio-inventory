# 操作和按钮逻辑

## 导航

第一版保留四个入口：

```text
扫码 / 库存 / 新增 / 流水
```

## 扫码页

固定按钮：

| 按钮 | 作用 |
|---|---|
| 开始扫码 | 开启内嵌相机预览 |
| 停止 | 停止相机 |
| 手电筒 | 相机运行时切换 torch |
| 手动输入 | 重量/数量或 payload 兜底 |
| 撤销 | 撤销上一笔写操作 |

上下文动作按钮按条件出现：

| 按钮 | 条件 |
|---|---|
| 入库 | 物品、重量/数量、库位齐全 |
| 出库 | 当前物品在库 |
| 更新重量/数量 | 当前物品在库且有新的重量/数量 |
| 绑定库位 | 当前物品在库且有新的库位 |
| 整理该库位 | 单独扫到库位码 |
| 完成整理 | 正在库位整理模式 |
| 归档 | 当前物品不是在库主流程，且用户进入详情操作 |

普通写操作都要按钮确认。库位整理模式进入后，连续扫已有库存物品会自动写库位。

## 库存页

控件：

```text
搜索
类型筛选
状态筛选
库位筛选
低库存筛选
```

默认只显示在库物品。

点击库存项进入详情，可查看固定字段、当前状态、流水摘要和可用操作。

## 新增页

新增页只生成标签，不保存库存。

按钮：

| 按钮 | 作用 |
|---|---|
| 生成 ID | 按类型生成默认唯一 ID |
| 生成 payload | 生成 `msi:v1` 字符串 |
| 复制 | 复制 payload |
| 打印 | 第一版占位 |
| 清空 | 清空当前表单 |

没有“保存并入库”。

## 流水页

展示最近 transactions。

写操作包括：

```text
stock_in
checkout
stocktake
move
archive
undo
```
